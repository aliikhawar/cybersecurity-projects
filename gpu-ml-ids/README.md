# GPU-Accelerated Machine Learning Intrusion Detection System

Detects network attacks (DoS, Port Scan, Brute Force, etc.) using PyTorch + CUDA and compares speedup against CPU.

## Tech Stack
- Python
- PyTorch (CUDA)
- NSL-KDD / CICIDS dataset

## Structure
- data/       → datasets
- src/        → source code
- notebooks/  → Jupyter notebooks
- models/     → saved models
- docs/       → documentation

What is implemented so far, and how to run it, is in [docs/progress.md](docs/progress.md).
